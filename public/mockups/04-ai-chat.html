The join happens in link-prs.mjs, which stamps a closedByPr field onto each closed issue. It matches in three passes, and the third one is where yours are falling through:

  • GitHub's own closing references from the timeline API
  • A fixes #NN / closes #NN keyword in the PR body
  • A bare #NN in the title — but only for issues already closed at fetch time

Because the issue snapshot is fetched before the merge in your deploy script, anything closed by the same PR still reads as open here. Swapping the two steps in refresh-issues.sh fixes all six of the missing links.
